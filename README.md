# 🍔 FoodieX

FoodieX is a modern food delivery web application inspired by popular food ordering platforms.  
It provides a smooth and interactive user experience with a clean UI, restaurant listings, food categories, cart system, and responsive design.

---

## 🚀 Live Demo

🔗 https://foodie-x.lovable.app

---

## ✨ Features

- 🍕 Modern Food Delivery UI
- 🔍 Restaurant & Food Search
- 🛒 Add to Cart System
- 📦 Orders Section
- 👤 User Profile Section
- 🌙 Dark Mode Support
- 📱 Fully Responsive Design
- 📍 Location Bar
- 🎨 Smooth Animations & Premium UI
- 💬 WhatsApp Order Integration
- 🔥 Mobile First Experience
